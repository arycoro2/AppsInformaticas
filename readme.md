## 🌟 Sobre este Repositorio

Este espacio está diseñado para ser el **cuaderno digital de la clase**. Aquí encontrarán todo el material teórico, ejemplos prácticos, guías y proyectos que iremos desarrollando a lo largo del año. La idea es aprender haciendo, equivocarnos y mejorar juntos en el fascinante mundo de la programación.

## 📚 Nuestra Ruta de Aprendizaje

A lo largo del curso, exploraremos los siguientes pilares del desarrollo de software. Haz clic en cada uno para expandir y ver los detalles.

<details>
<summary><b>🧠 1. Fundamentos del Software</b></summary>
<br>
  
  *   ¿Qué es el Software? Diferencia con el Hardware.
  *   Tipos de Software: Sistemas Operativos vs. Aplicaciones.
  *   El ciclo de vida del desarrollo de software (SDLC).
  *   Algoritmos: El corazón de la lógica de programación. 💡

</details>

<details>
<summary><b>💻 2. Lógica de Programación</b></summary>
<br>
  
  *   Variables y Tipos de Datos (Números, Texto, Booleanos). 🔢
  *   Estructuras de Control: Condicionales (if/else) y Bucles (for/while). 🔄
  *   Funciones: Cómo organizar y reutilizar nuestro código. 🧩
  *   Primeros pasos con un lenguaje (ej. Python, JavaScript, PSeInt).

</details>

<details>
<summary><b>🌐 3. Desarrollo de Aplicaciones Web</b></summary>
<br>
  
  *   **HTML:** La estructura de una página web. 🏗️
  *   **CSS:** Darle estilo y color a nuestras creaciones. 🎨
  *   **JavaScript:** Hacer que nuestras páginas sean interactivas. ✨
  *   Proyecto: Crear una pequeña página web personal.

</details>

<details>
<summary><b>📱 4. Introducción a Bases de Datos</b></summary>
<br>
  
  *   ¿Para qué sirve una base de datos?
  *   Conceptos básicos: Tablas, registros y campos. 🗃️
  *   Introducción a SQL para consultar información. 📝

</details>

<details>
<summary><b>🚀 5. Proyecto Final Integrador</b></summary>
<br>
  
  *   Aplicar todo lo aprendido para resolver un problema real.
  *   Trabajo en equipo y uso de Git/GitHub para colaborar. 🤝
  *   Presentación de la aplicación final.

</details>
